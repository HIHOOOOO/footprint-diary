### 사이드바 광고 위치 정책 문제 발견

광고 가이드 문서(`Ads develop.md`, 출시 체크리스트)를 검토하는 과정에서 두 가지 제약을 확인했다.

**제약 1 - 스크롤 화면 전용**: 출시 체크리스트 "배너 광고 스크롤 화면만" 항목. 사이드바는 드로어(drawer) 형태로 스크롤 가능한 화면이 아니다.

**제약 2 - 뷰포트 전체 너비**: 가이드에서 배너 컨테이너 `width`는 항상 뷰포트 전체 너비와 동일해야 한다고 명시(`100%` = 화면 전체). 사이드바는 `max-w-xs`(최대 320px)로 제한된 패널이라 조건을 만족하지 못한다.

사이드바에 달면 안 되는 거 아니냐고 했더니 사용자가 굉장히 곤란해했다. 메인 발자국 화면 하단은 플러스 버튼이 차지하고 있고, 메인 캔버스 자체가 DOM 스크롤이 아닌 canvas 렌더링이라 "스크롤 화면"으로 볼 수 없다. 현실적인 대안은 LogsPage(기록 모아보기) 스크롤 목록 하단이다.

다만 이 시점에 기획을 뒤엎기가 싫다는 의견이 있어서, 일단 사이드바에 달아둔 채 심사에 제출해보기로 결정. 통과하면 유지, 반려되면 LogsPage로 이동한다. 결과가 나올 때까지는 백로그로 관리.

### toss-release 체크리스트 실전 가동

새로 정비한 `/toss-release` 스킬을 이 프로젝트에 실제로 돌렸다. 결과는 아래와 같다.

- **앱 타입**: WebView (`@apps-in-toss/web-framework`) ✅
- **SDK**: 2.0.5 최신 ✅
- **TDS**: `@toss/tds-mobile 2.2.1` 설치, 주요 컴포넌트 실제 사용 ✅
- **광고**: 실 ID로 교체 완료, 위치 정책 문제는 백로그 ⚠️
- **보안**: 외부 API는 Nominatim 역지오코딩만 (공개 API, 키 없음) ✅
- **코드 리뷰**: HIGH 4개 발견 — 그 중 심각한 2개를 백로그에 기록

코드 리뷰에서 나온 HIGH 이슈 중 즉시 수정이 필요한 두 가지:

**GPS 거부 시 consent 미저장**: "허용 안 할게요"를 눌러도 `localStorage`에 `gps-consent: 'false'`가 저장되지 않아서, 발자국을 추가할 때마다 동의 팝업이 반복해서 뜨는 버그다. `Footprint.jsx:526` 수정 필요.

**reverseGeocode 타임아웃 없음**: Nominatim API fetch에 `AbortSignal`이 없어서 네트워크가 느린 환경에서 로딩 스피너가 무한 지속될 수 있다. `AbortSignal.timeout(5000)` 추가 필요. `Footprint.jsx:315` 수정 필요.

두 항목 모두 이번 세션에서 수정하지 않고 백로그로 남겼다. 사용자가 번들을 먼저 제출하고 싶어해서 수정은 다음 세션으로 미룬 것.

- **아이콘/썸네일**: granite.config.ts의 CDN URL 설정 완료 ✅
- **샌드박스**: 인앱 광고는 샌드박스 테스트 불가 — QR 토스앱 테스트 필요 ⚠️
- **빌드**: 에러 없이 `footprint-diary.ait` 생성 성공 ✅
